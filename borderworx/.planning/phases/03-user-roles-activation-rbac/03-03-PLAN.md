the frontend calls `POST /api/auth/activate` (with the fresh Supabase access token) before
redirecting to the dashboard.

Purpose: This is the trigger that flips the user pending -> active. Without it, the backend
endpoint from 03-01 is never called and the user still hits "Account pending".
Output: A small `activation.api.ts` module API and a modified set-password page.
