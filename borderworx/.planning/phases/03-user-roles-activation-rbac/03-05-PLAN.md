    1. `src/shared/auth/accessErrorMessage.ts` — string-only, no internal imports:
       `export function friendlyAccessMessage(err: unknown): string | null {
          const msg = err instanceof Error ? err.message : typeof err === 'string' ? err : '';
          if (msg.startsWith('Account ')) return 'Your account is not active yet. Please finish activation or contact an administrator.';
          if (msg.startsWith('Missing permission:')) return 'You do not have permission to view this. Contact an administrator if you need access.';
          return null;
        }`
       Export it from `src/shared/auth/index.ts` (add to the existing barrel from 03-04; do not remove existing exports).

         omit the toolbar otherwise).

         string, render that friendly message instead of the raw error/table.
