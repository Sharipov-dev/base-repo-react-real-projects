<objective>
Make `roleId` mandatory at user-create time so no role-less (and therefore permission-less)
users can be invited.

Purpose: A user with no role holds zero permissions and is 403'd on everything even after
activation. Requiring a role at invite eliminates that class of broken account.
Output: `createUserSchema` in `user.dto.ts` requires a valid `roleId` UUID; `updateUserSchema`
is left untouched (admins can still change roles via the edit flow).
</objective>
